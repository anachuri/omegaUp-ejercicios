=====================================================
  ALGORITMOS DE ORDENACION EN LA STL DE C++
=====================================================

Todos estos algoritmos estan en:
    #include <algorithm>

Trabajan sobre iteradores, por lo que sirven con vector, array,
deque, string, y en general cualquier contenedor con acceso
aleatorio (random access iterators).

-----------------------------------------------------
1) sort(first, last)
-----------------------------------------------------
Firma:
    template <class RandomIt>
    void sort(RandomIt first, RandomIt last);

    template <class RandomIt, class Compare>
    void sort(RandomIt first, RandomIt last, Compare comp);

Descripcion:
    Ordena el rango [first, last) de forma ascendente por defecto.
    Es un algoritmo hibrido llamado "introsort":
        - Empieza con quicksort.
        - Si la recursion es demasiado profunda (riesgo de O(n^2)),
          cambia a heapsort.
        - Para sub-arreglos pequeños, usa insertion sort.

Complejidad: O(n log n) en el peor caso (garantizado por el estandar
desde C++11).
Estabilidad: NO estable.

Ejemplos:
    vector<int> v = {5, 2, 8, 1, 9};
    sort(v.begin(), v.end());               // 1 2 5 8 9
    sort(v.begin(), v.end(), greater<int>()); // 9 8 5 2 1

    // con lambda
    sort(v.begin(), v.end(), [](int a, int b) {
        return a > b; // descendente
    });

2) stable_sort(first, last)
-----------------------------------------------------
Firma:
    template <class RandomIt>
    void stable_sort(RandomIt first, RandomIt last);

    template <class RandomIt, class Compare>
    void stable_sort(RandomIt first, RandomIt last, Compare comp);

Descripcion:
    Igual que sort(), pero garantiza que los elementos considerados
    "iguales" segun el comparador mantienen su orden relativo original.
    Internamente usa merge sort (o una variante).

Complejidad: O(n log n) si hay memoria auxiliar disponible;
             O(n log^2 n) en el peor caso si la memoria es insuficiente.
Estabilidad: SI estable.

Ejemplo tipico: ordenar por varios criterios en pasos separados.
    struct Persona { string nombre; int edad; };
    vector<Persona> p = {{"Ana", 30}, {"Luis", 25}, {"Eva", 30}};

    // primero ordenamos por nombre (orden secundario)
    stable_sort(p.begin(), p.end(), [](auto &a, auto &b) {
        return a.nombre < b.nombre;
    });
    // despues por edad (orden primario), sin perder el orden de nombre
    stable_sort(p.begin(), p.end(), [](auto &a, auto &b) {
        return a.edad < b.edad;
    });

3) partial_sort(first, middle, last)
-----------------------------------------------------
Firma:
    template <class RandomIt>
    void partial_sort(RandomIt first, RandomIt middle, RandomIt last);

    template <class RandomIt, class Compare>
    void partial_sort(RandomIt first, RandomIt middle, RandomIt last, Compare comp);

Descripcion:
    Reordena el rango de forma que los elementos en [first, middle)
    sean los mas pequeños de todo el rango [first, last), y queden
    ordenados entre si. Los elementos en [middle, last) quedan en
    orden no especificado.

Complejidad: O(n log k), donde k = distancia(first, middle).
Estabilidad: NO estable.

Ejemplo (obtener los 3 menores, ordenados):
    vector<int> v = {9, 3, 7, 1, 8, 2, 5};
    partial_sort(v.begin(), v.begin() + 3, v.end());
    // v[0..2] = {1, 2, 3} (ordenados), el resto en cualquier orden

-----------------------------------------------------
4) partial_sort_copy(first, last, d_first, d_last)
-----------------------------------------------------
Firma:
    template <class InputIt, class RandomIt>
    RandomIt partial_sort_copy(InputIt first, InputIt last,
                                RandomIt d_first, RandomIt d_last);

Descripcion:
    Copia los elementos ordenados (o parcialmente ordenados si el
    destino es mas chico que el origen) desde [first, last) hacia
    [d_first, d_last), sin modificar el rango original.

Complejidad: O(n log k), k = tamaño del destino.

Ejemplo:
    vector<int> origen = {5, 3, 9, 1, 7};
    vector<int> destino(3);
    partial_sort_copy(origen.begin(), origen.end(),
                       destino.begin(), destino.end());
    // destino = {1, 3, 5} (los 3 menores, ordenados)
    // origen queda intacto

5) nth_element(first, nth, last)
-----------------------------------------------------
Firma:
    template <class RandomIt>
    void nth_element(RandomIt first, RandomIt nth, RandomIt last);

    template <class RandomIt, class Compare>
    void nth_element(RandomIt first, RandomIt nth, RandomIt last, Compare comp);

Descripcion:
    Reordena el rango de forma que el elemento en la posicion "nth"
    es el que estaria en esa posicion si todo el rango estuviera
    ordenado. Todos los elementos antes de "nth" son <= que el,
    y todos los de despues son >= que el (pero NO estan ordenados
    entre si).

Complejidad: O(n) en promedio (algoritmo tipo quickselect).
Estabilidad: NO aplica (no ordena completamente).

Ejemplo (encontrar la mediana):
    vector<int> v = {9, 3, 7, 1, 8, 2, 5};
    int k = v.size() / 2;
    nth_element(v.begin(), v.begin() + k, v.end());
    cout << v[k]; // la mediana

6) is_sorted(first, last) / is_sorted_until(first, last)
-----------------------------------------------------
Firma:
    template <class ForwardIt>
    bool is_sorted(ForwardIt first, ForwardIt last);

    template <class ForwardIt>
    ForwardIt is_sorted_until(ForwardIt first, ForwardIt last);

Descripcion:
    is_sorted() devuelve true si el rango ya esta ordenado
    ascendentemente (o segun el comparador dado).
    is_sorted_until() devuelve un iterador al primer elemento que
    rompe el orden (o "last" si todo esta ordenado).

Complejidad: O(n).

Ejemplo:
    vector<int> v = {1, 2, 3, 5, 4};
    cout << is_sorted(v.begin(), v.end()); // false
    auto it = is_sorted_until(v.begin(), v.end());
    cout << *it; // 4 (primer elemento fuera de orden)

7) inplace_merge(first, middle, last)
-----------------------------------------------------
Firma:
    template <class BidirIt>
    void inplace_merge(BidirIt first, BidirIt middle, BidirIt last);

Descripcion:
    Fusiona dos rangos consecutivos YA ORDENADOS ([first, middle) y
    [middle, last)) en un solo rango ordenado. Es basicamente el
    paso de "merge" de merge sort, expuesto como funcion aparte.

Complejidad: O(n log n) en general, O(n) si hay memoria auxiliar
suficiente.
Estabilidad: SI estable.

Ejemplo:
    vector<int> v = {1, 3, 5, 2, 4, 6};
    // [1,3,5) y [2,4,6) ya estan ordenados por separado
    inplace_merge(v.begin(), v.begin() + 3, v.end());
    // v = {1, 2, 3, 4, 5, 6}

8) FUNCIONES DE HEAP: make_heap, push_heap, pop_heap, sort_heap
-----------------------------------------------------
Firmas:
    template <class RandomIt>
    void make_heap(RandomIt first, RandomIt last);

    template <class RandomIt>
    void push_heap(RandomIt first, RandomIt last);

    template <class RandomIt>
    void pop_heap(RandomIt first, RandomIt last);

    template <class RandomIt>
    void sort_heap(RandomIt first, RandomIt last);

Descripcion:
    Permiten construir y manipular un max-heap manualmente sobre
    un contenedor de acceso aleatorio (por defecto, orden ascendente
    al final si se usa sort_heap). Es la base de heap sort, y sirve
    para implementar colas de prioridad manuales.

    - make_heap: reordena [first, last) para que cumpla la
      propiedad de heap.
    - push_heap: asume que [first, last-1) ya es un heap y que el
      ultimo elemento se acaba de agregar; lo reacomoda.
    - pop_heap: mueve el maximo (front) al final y reacomoda el
      resto como heap (no lo elimina del contenedor, solo lo mueve).
    - sort_heap: ordena completamente un rango que ya es un heap
      (destruye la propiedad de heap en el proceso).

Complejidad: O(log n) para push/pop, O(n) para make_heap,
             O(n log n) para sort_heap.

Ejemplo (heap sort manual con la STL):
    vector<int> v = {5, 3, 8, 1, 9, 2};
    make_heap(v.begin(), v.end());     // construye el heap
    sort_heap(v.begin(), v.end());     // ordena usando el heap
    // v = {1, 2, 3, 5, 8, 9}

Ejemplo (simular una priority_queue a mano):
    vector<int> v;
    v.push_back(5); push_heap(v.begin(), v.end());
    v.push_back(1); push_heap(v.begin(), v.end());
    v.push_back(9); push_heap(v.begin(), v.end());

    pop_heap(v.begin(), v.end()); // el maximo pasa al final
    int maximo = v.back();
    v.pop_back();

Nota: en la practica, para una cola de prioridad se recomienda usar
directamente std::priority_queue (mas simple y con la misma
complejidad).

-----------------------------------------------------
9) RESUMEN DE COMPLEJIDADES
-----------------------------------------------------

Funcion              | Complejidad temporal   | Estable | Ordena todo
--------------------------------------------------------------------
sort                  | O(n log n) peor caso    | No      | Si
stable_sort           | O(n log n)              | Si      | Si
partial_sort          | O(n log k)              | No      | Solo k
partial_sort_copy     | O(n log k)              | No      | Solo destino
nth_element           | O(n) promedio           | No      | No
is_sorted             | O(n)                    | -       | -
inplace_merge         | O(n log n) / O(n)       | Si      | Si
make_heap             | O(n)                    | No      | No
push_heap / pop_heap  | O(log n)                | No      | No
sort_heap             | O(n log n)              | No      | Si

-----------------------------------------------------
10) CUANDO USAR CADA UNA
-----------------------------------------------------
- Necesitas ordenar todo el rango, sin mas requisitos -> sort()
- Necesitas mantener el orden relativo de elementos iguales
  (ej: ordenar por varios criterios en pasos) -> stable_sort()
- Solo necesitas los k menores/mayores, ordenados -> partial_sort()
- Solo necesitas los k menores/mayores en OTRO contenedor,
  sin tocar el original -> partial_sort_copy()
- Necesitas el elemento que ocuparia la posicion k (mediana,
  percentil, etc.) sin ordenar todo -> nth_element()
- Necesitas verificar si algo ya esta ordenado antes de procesarlo
  -> is_sorted() / is_sorted_until()
- Tenes dos mitades ya ordenadas y queres combinarlas -> inplace_merge()
- Necesitas una cola de prioridad manual sobre un vector existente
  -> make_heap / push_heap / pop_heap / sort_heap
  (aunque en la practica casi siempre es mas simple usar
  std::priority_queue)
